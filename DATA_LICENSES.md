# Data licences

The code in this repository is MIT-licensed. The data it downloads is not included in the
repository; it is fetched from Zenodo at run time and is used under its own licences.

| Dataset | Licence | DOI |
|---|---|---|
| *Sensor-Based Operational Dataset of Main Ship Machinery (ARC Gloria)* | CC BY 4.0 | [10.5281/zenodo.18330661](https://doi.org/10.5281/zenodo.18330661) |
| *Marine Engine Fault Dataset* (BahooToroody, Bondarenko, Abaei, Niki, Zio, 2026) | CC BY 4.0 | [10.5281/zenodo.19857425](https://doi.org/10.5281/zenodo.19857425) |

Data transformed (resampled, mapped, fault-injected) for demonstration. The three "vessels" are
virtual: contiguous voyage legs of the one real ship, shifted in time. The fault is injected from a
different (test-bench) engine. The detector is demonstrated, not validated.
